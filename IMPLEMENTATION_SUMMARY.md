## 📚 What Was Built

A **revolutionary AI-powered personalized interview preparation system** that:
- 🤖 Generates questions based on YOUR GitHub projects and tech stack

- ⏱️ Provides real-time mock interviews with timers

- 📈 Tracks progress and provides personalized improvement plans

## 🔄 Data Flow

```
User Opens Interview Prep
    ↓
GitHub Profile Synced (tech stack, projects, skills)
    ↓
User Selects Mode & Difficulty
    ↓
Questions Generated by Groq AI (personalized)
    ↓
User Answers Questions (with optional timer)
    ↓
Answers + Profile Sent to Groq AI
    ↓
AI Evaluates & Scores
    ↓
Feedback Displayed (scores, suggestions, learning path)
    ↓
Results Saved (for progress tracking)
```

## 🤖 AI Integration (Groq)

**Model Used:** llama-3.3-70b-versatile
**Provider:** Groq API

### Question Generation
- Context: User's tech stack, projects, experience
- Output: 5 personalized questions per session
- Customization: By skill type and difficulty

### Evaluation
- Input: Questions + User answers
- Scoring: Considers completeness, clarity, relevance, practical knowledge
- Output: Score, feedback per question, overall analysis, improvement suggestions
